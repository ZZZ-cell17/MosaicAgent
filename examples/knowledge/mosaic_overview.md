# MosaicAgent 示例知识

MosaicAgent 是一个用于学习的多模态知识 Agent。它由 JoyAgent-JDGenie 的 MRAG 模块删减和整理而来，当前采用单 Agent 架构。

## 入库链路

文档进入系统后，依次经过格式解析、页面渲染、文本切块、OCR、图片描述和向量化。文本向量、BM25 稀疏向量、图片向量与页面向量写入 Qdrant，知识库和文件状态写入 SQLite。

## 问答链路

Agent 首先判断问题是否需要检索。需要检索时，它会扩展子问题，并行执行文本向量、BM25、图片和页面检索。每轮检索后，Agent 总结结果并判断信息是否充分；不足时改写问题进入下一轮，最多运行 `MRAG_MAX_ROUNDS` 轮。

检索结束后，系统合并与去重结果，对文本片段进行重排。如果只有文本证据，就由 LLM 回答；如果命中重要页面图片，就把文本证据和页面图片一起交给 VLM 回答。

## 项目边界

学习版不包含 Data Agent、NL2SQL、Deep Search、报告生成、代码解释器、Java 后端或 Web UI。当前也不保存跨请求的长期对话记忆。
